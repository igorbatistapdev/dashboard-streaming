Streaming no Brasil

Análise de dados sobre o consumo e o comportamento dos usuários de plataformas de streaming no Brasil.

O projeto transforma uma base simulada de consumo em indicadores, gráficos e interpretações, apoiando a leitura de padrões entre plataformas, categorias, gêneros e períodos.

Sobre o projeto

Entendendo o consumo de streaming

O problema analisado é como consumo, receita, assinaturas e avaliações se distribuem entre plataformas de streaming ao longo do tempo.

Objetivo

Identificar padrões de utilização e comparar plataformas, categorias e gêneros com indicadores calculados diretamente dos dados.

Fonte dos dados

Arquivo simulacao_streaming_brasil.csv, uma base simulada, usada com fins acadêmicos. Os resultados não representam o mercado real.

Relevância

Medir o comportamento de consumo orienta decisões sobre catálogo, horários de maior audiência e desempenho financeiro das plataformas.

Como funciona

Do dado à decisão

  1. Disponibilização dos dadosBase CSV versionada no repositório.
  2. Tratamento da baseTipos, duplicidades, nulos e atributos derivados.
  3. Análise exploratóriaNotebook com Pandas, Matplotlib e Seaborn.
  4. Criação dos indicadoresKPIs calculados a partir dos dados filtrados.
  5. VisualizaçãoGráficos e textos interpretativos automáticos.
  6. Dashboard interativoFiltros, comparativos e download dos dados.
