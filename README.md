# 🎬 Streaming Brasil Analytics

> **Análise e visualização de dados sobre plataformas de streaming no Brasil.**

Projeto acadêmico desenvolvido para explorar padrões de consumo, receita, assinaturas e avaliações de plataformas de streaming ao longo do tempo.

A solução combina **análise exploratória, visualizações interativas e dashboard**, utilizando uma base de dados simulada.

## Visão geral

A análise utiliza uma base **simulada**, composta por:

- **4.440 registros mensais**
- **2015–2024**
- **14 variáveis**
- **5 plataformas**

> Os dados são exclusivamente acadêmicos e não representam dados reais do mercado brasileiro.
